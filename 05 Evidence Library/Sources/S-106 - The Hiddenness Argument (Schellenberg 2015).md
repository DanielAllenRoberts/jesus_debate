# S-106 — The Hiddenness Argument (Schellenberg 2015)

## Explain for the reader

Schellenberg’s short Oxford book restates the hiddenness argument for a broad audience: a perfectly loving God would always be open to relationship, which would preclude nonresistant nonbelief. Anti uses it as the clearest primary statement of the contemporary argument.

## Summary (neutral)

Accessible reconstruction of the hiddenness argument, distinguishing it from the problem of evil, clarifying “openness” to relationship, and arguing that nonresistant nonbelief is actual. Concludes against personal classical theism while leaving room for non-personal “ultimism.”
