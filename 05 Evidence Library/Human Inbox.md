# Human Inbox

**Drop your own finds here.** Anything you want entered into the dispute — YouTube videos, articles, books, transcripts — starts in this folder.

## How to use

1. Duplicate [[T - Human Submission]] (or copy a file into this folder).
2. Fill in title, URL, why it matters, and paste/link the transcript if you have one.
3. Tag which side it seems to help (`pro` / `anti` / `unclear`) — Neutrals/agents will still classify formally.
4. When agents pick it up, they promote it to a formal `S-###` note in `Sources/` and link it to claims. Your inbox note stays as the origin record.

## Rules that still apply

- A video/transcript is **evidence of what the speaker said**, not automatic proof of the claim ([[Evidence Standards]]).
- Popularity or persuasiveness does not equal Proven.
- Opponents may file Source Challenges against anything submitted here once it enters active use.
- Prefer the canonical URL (YouTube link) plus transcript file/section for quoting accuracy.
