## 2. Which Pro claims are most threatened (and why)

Ordered by Phase 3 urgency for Pro (not a score):

1. **[[C-006]] / [[C-A001]] — Resurrection**  
   Dual fire from [[A-ANTI-001]] (vision/grief origin; empty tomb as legend) and [[A-ANTI-006]] (post-70 dating → passion/tomb development). Directly contests [[A-PRO-004]] and [[A-PRO-011]]. If this hinge slips, [[A-PRO-005]]’s vindication path into [[C-003]] weakens.

2. **[[C-001]] / [[C-A002]] — Classical theism**  
   [[A-ANTI-002]] stacks logical/evidential evil ([[S-060]], [[S-061]], [[S-021]]), hiddenness ([[S-062]], [[S-063]]), and systematic atheist philosophy ([[S-022]], popularizers [[S-016]], [[S-024]]). Hits foundation weight on the truth stack; threatens [[A-PRO-001]], [[A-PRO-002]], [[A-PRO-006]].

3. **[[C-003]] / [[C-A003]] — Divine Son / atonement package**  
   [[A-ANTI-004]] (post-death exaltation development) + [[A-ANTI-005]] (pluriform → later winner) contest early high Christology ([[A-PRO-008]]) and resurrection-as-vindication ([[A-PRO-005]]). Even a historical Jesus + crucifixion would not salvage Nicene/salvific identity if this package sticks.

### High / medium threat

4. **[[C-002]] — God of the Bible**  
   [[A-ANTI-003]] attacks moral/empirical fitness of the biblical God (popular polemics [[S-016]]–[[S-018]], [[S-024]]; Ehrman theodicy [[S-065]]; Bible-history / debate media [[S-084]], [[S-081]], [[S-092]]). Can detach “some deity” from “biblical God” even if [[C-001]] partly holds.

### Lower threat (still note for Phase 3)

5. **[[C-004]] — Historical Jesus**  
   [[A-ANTI-007]] does **not** press mythicism; it marks mythicism fringe and steers Anti toward naturalistic alternatives. Net: softens Anti overclaim risk; Pro’s [[A-PRO-003]] / [[A-PRO-009]] are not the main front — but Pro must not treat Anti’s anti-mythicism as endorsement of Pro’s full HJ reconstruction.

6. **[[C-005]] — Crucifixion**  
   No dedicated Anti argument filed against it. Indirect pressure only via [[A-ANTI-006]] / [[S-078]] (passion narrative development; burial skepticism). Keep watch in Phase 3 when answering empty-tomb / burial premises in [[A-PRO-011]].

## 4. Symmetry risks ([[Constitution]] §2)

Methods Anti used that Pro **also** relies on — accepting them without a principled, cited distinction locks them for both sides:

1. **Critical dating & literary development**  
   Anti: post-70 Gospels + passion/tomb embossing ([[A-ANTI-006]], [[S-076]], [[S-078]]).  
   Pro: early creed dating / minimal-facts timelines ([[A-PRO-004]], [[A-PRO-011]], [[A-PRO-008]]).  
   Risk: if “decades allow legendary growth” is allowed as a general historical method, Pro must show why 1 Cor 15 / appearance tradition escape it — or accept parallel scrutiny.

2. **Appeal to scholarly consensus / critical specialists**  
   Anti: Ehrman dating, Bauer/Pagels diversity, Casey vs mythicism.  
   Pro: Habermas consensus facts, Hurtado early devotion, Wright historiography.  
   Risk: “consensus settles it” cuts both ways; selective consensus-shopping is special pleading under §2.

3. **Psychological / naturalistic accounts of religious experience**  
   Anti: grief visions ([[S-027]], [[S-077]]).  
   Pro: if Phase 3 leans on conversion psychology or “appearances as experiences,” the same explanatory genre stays open to Anti.

4. **Philosophical cumulative / probabilistic framing**  
   Anti: evil + hiddenness against classical theism.  
   Pro: kalām / fine-tuning / moral law cumulative case ([[A-PRO-001]], [[A-PRO-006]], [[A-PRO-002]]).  
   Risk: once cumulative probability talk is in play, Anti’s evil/hiddenness packages must be weighed on the same ledger — not dismissed as “theology.”

5. **Textual criticism & manuscript arguments**  
   Anti: [[S-026]], contradiction catalogs ([[S-066]]).  
   Pro: reliability / recovery via [[A-PRO-007]] (Wallace/Bruce-type lines).  
   Risk: granting aggressive textual instability for Anti’s Christology story while claiming rock-solid recovery for Pro’s biblical God claim needs a cited distinction.

6. **Development narratives**  
   Anti: exaltation → Nicene ([[A-ANTI-004]], [[A-ANTI-005]]).  
   Pro: early high Christology continuity ([[A-PRO-008]]).  
   Risk: both sides use “trajectory from earliest sources”; Pro cannot ban development language while using developmental apologetics (e.g. creed → Gospel).

7. **Anti-mythicism as method hygiene ([[A-ANTI-007]])**  
   Pro benefits if mythicism is fringe — but under symmetry, Pro also should not overclaim from “Jesus existed” to “resurrection / Nicene identity.” [[A-ANTI-007]] is a restraint Pro should mirror in reverse (no overclaim from HJ security).

**§1 reminder:** Anti theses are still Phase 1 filings with `unreviewed` sources. Pro cross-read ≠ conceding their truth; inference must stay labeled; scoring waits for Phase 4.
