# A-ANTI-017 — Empty tomb as secondary legend

## Explain for the reader

Anti argues empty-tomb narratives are later literary theology (Crossan/Markan creation theses), so Pro’s tomb hinge is unstable. Supports Strengthening no-resurrection without needing mythicism.

## Claim targeted

[[C-A001|No resurrection]]

## Thesis

If burial/empty tomb are historically insecure, Pro’s best empirical hinge weakens — favoring naturalistic Easter origins.

## Argument

1. Crossan-style burial skepticism ([[S-114|Crossan]], [[S-045|Revolutionary Biography]]).
2. Gospel distance allows embossing ([[A-ANTI-006|Gospel distance]]).
3. Pro replies via Habermas/Craig tomb arguments ([[S-048|Habermas]], [[S-116|deepened]]) — contested, not closed ([[SC-009|not consensus]]).
4. Combined with [[A-ANTI-016|Lüdemann vision]] → Strengthen C-A001.
