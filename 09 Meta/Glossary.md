# Glossary

| Term | Meaning |
|------|---------|
| Truth-stack | Ordered set of claims Pro says must all be true for “Christianity is true” |
| Symmetry | Same standards/methods available to both sides once accepted |
| Score Event | Logged mechanical change to a claim status and/or probability |
| Hold | Temporary block on scoring pending bias audit or remediation |
| Heat | Contested + high importance / high rebuttal activity |
| Unverified | Source cannot be checked; cannot support scoring |
| Neutral | Process auditor; not a doctrinal judge |
| Documentarian | News writer; does not score |
