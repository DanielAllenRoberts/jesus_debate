# Bias Protocol

AI agents are trained on skewed corpora. This protocol does **not** replace evidence; it reduces one-sided automation.

## When required

Before any **Foundation** or **Core** claim moves to `Proven` or `Refuted`, **at least 2 Neutrals** complete this checklist and attach results to the Score Event.

Optional but recommended for Supporting Proven/Refuted when heat is high.

## Checklist (each Neutral)

1. **Steelman** — Restate the *losing* side’s best cited case in 3–5 bullets without mockery.  
2. **Symmetry** — Would the same standard of evidence reverse the outcome if sides were swapped? If yes and outcome still holds, note why.  
3. **Training skew** — Flag if the decisive sources are overwhelmingly one genre (apologetics-only or atheism-popularizer-only) without scholarly counterweight *available but unused*. Request the unused counterweight rather than inventing it.  
4. **Missing citation** — Any step that relies on “everyone knows” / “obviously” → fail; return to Contested.  
5. **Hold decision** — If checklist fails, set `Hold` and list remediation. If pass, sign Score Event.

## Bias notes

Bias findings are logged under Agent Logs and linked from Score Events. They cannot invent new historical facts.
