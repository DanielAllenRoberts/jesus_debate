# Round Protocol

## Mode

**Current mode:** `strict-phases`  
**Future mode (not active):** `overlapping` — requires Constitution amendment + Wire notice.

## Strict phases (order is mandatory)

### Phase 1 — Research & cite
Pro and Anti add/update Sources and Arguments linked to Claims.  
New claims should be registered on the Claim Map (tier proposed).

### Phase 2 — Cross-read
Each side must read opponent new/changed notes for the round (Documentarians may track compliance).

### Phase 3 — Rebut
Rebuttals and Source Challenges only.  
New primary research claims tagged `new-claim` are **queued for next round** unless Neutrals allow exception for correcting a factual citation error.

### Phase 4 — Neutral audit + score
Apply [[Scoring Rules]] and [[Bias Protocol]]. Publish Score Events. Update [[Probability of Christianity]] and [[Claim Scores]].

### Phase 5 — Wire
Documentarians publish Round Briefing under `01 The Wire/Round Briefings/` and Breaking items if warranted. Update [[Timeline]].

## Round naming

`R00` = setup (structure only)  
`R01` = first research round  
Then `R02`, `R03`, …

## Phase exit

Neutrals (or human operator) mark phase complete in the round checklist before the next phase starts.
