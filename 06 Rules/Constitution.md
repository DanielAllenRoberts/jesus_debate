# Constitution

> [!important] Master law of this vault
> All agents are bound by these rules. Scoreboard outcomes that violate this Constitution are void until corrected.

## 1. Facts only — no assumptions

Every assertion that supports or attacks a claim must be backed by a cited source in [[05 Evidence Library/Sources]].  
Inference must be labeled as inference. Inference alone cannot move scores until independently backed.

## 2. Symmetry (concept lock)

Once a concept, method, standard, or form of argument is accepted for one side, it applies to both.  
You may not use a form of argument for your side and deny it to the other without a **principled, cited** distinction. Special pleading is a rules violation.

## 3. Allowed viewpoints

Arguments must be framed **historically**, **philosophically**, and/or **scientifically**.  
Theology may appear as *claim content*. “Because faith says so” is not evidence.

## 4. Personal experience

Disallowed unless attached to clear, independently checkable proof that meets [[Evidence Standards]].

## 5. Claim stack ownership

**Pro** defines what “Christianity is true” requires in [[Christianity Truth Stack]].  
**Anti** attacks that stack and may introduce counter-claims.  
**Neutrals** police process and apply mechanical rules — they do not redefine doctrine.

## 6. Full citation

Every research/argument note links sources via Obsidian `[[wikilinks]]` (see §11). Missing URLs or unverifiable references are marked `unverified` and **cannot support scoring**.  
Opponents may challenge credibility via notes in `05 Evidence Library/Source Challenges/`.

## 7. Scoring gate

Only mechanically scored claim statuses (via [[Scoring Rules]] and Neutral sign-off) move [[Probability of Christianity]].  
[[01 The Wire/Wire Index|The Wire]] narrates; it never overrides the Scoreboard.

## 8. AI bias protocol

Agents flag training-skew risks. Neutrals run [[Bias Protocol]] audits on high-impact score changes.  
Bias notes cannot replace evidence; they may trigger re-check or place a claim on `Hold`.

## 9. Tier consensus; Neutrals break ties

Pro + Anti + Neutrals seek agreement on each claim’s importance tier.  
After the challenge window in [[Scoring Rules]], Neutrals may lock the tier.

## 10. Round discipline

Early mode uses strict phases in [[Round Protocol]].  
Overlapping mode requires an explicit rules amendment note before use.

## 11. Mandatory Obsidian wikilinks

Every claim, argument, source, rebuttal, source challenge, score event, and Wire note that references another vault entity **MUST** use `[[wikilinks]]`. Bare IDs in plain text alone (e.g. typing `C-001` without `[[C-001]]`) do **not** satisfy this rule.

| Note type | Required wikilinks |
|-----------|-------------------|
| Arguments | Target claim(s) and every cited source note |
| Sources | Claims they support or attack |
| Claims | Linked lists of related arguments and sources (explicit sections, and/or kept current via backlinks + those sections) |
| Rebuttals / Source Challenges / Score Events | Target claim(s), argument(s), and/or source(s) they act on |
| Indexes and [[01 The Wire/Wire Index\|The Wire]] | Every vault entity they mention |

**External** URLs remain normal markdown links (`[label](https://…)`). **Internal** vault links must be Obsidian wikilinks.  
This rule does not change [[Scoring Rules]] math; it governs how the graph is wired. See also [[Evidence Standards]] and §12.

## 12. Readable labels & learnable narration

Coded entity IDs (`C-` / `A-` / `S-` / `R-` / `SC-` / `SE-` / `H-`) are for the graph — **not** primary human prose. Humans must be able to **read and learn** from this vault without hopping notes just to decode what a code means. This rule is about **explanation**, not merely labeled links.

### A. Labels (every coded wikilink)

Every wikilink to a coded entity **MUST** include plain-language context in the same sentence **or** use Obsidian display text `[[Note|human label]]`. Bare “see [[R-001]]” (or bare ID lists with no gloss) is a **rules violation**.

| | Example |
|---|---|
| **Good** | `[[R-001\|Pro rebuttal: empty-tomb women-witnesses]] argues that…` |
| **Good** | `[[C-006\|Resurrection]] was Strengthened because…` |
| **Bad** | `Rebuttals [[R-001]] [[R-002]] and challenges [[SC-001]]` |

Prefer wording a non-specialist can follow (`the claim that Jesus rose from the dead`); put the code in display-text or parentheses.

### B. Self-contained narrative docs (learn from one document)

[[01 The Wire/Wire Index|The Wire]], Scoreboard narrative notes, round briefings, Breaking items, and agent/round logs that **mention** a claim, argument, rebuttal, source challenge, or score event must be **self-contained enough to learn from**. For each such mention, include all three:

1. **Human label** — display-text or in-sentence plain language (§12A)
2. **One-sentence explanation** — what the point *is* (substance, not just the ID)
3. **Why it matters** — for the [[Christianity Truth Stack]] and/or the probability story

Wire **must narrate and teach**; it must not dump coded link lists. Style guide: [[Writing for Humans]].  
This rule does not change [[Scoring Rules]] math.

## Amendments

Amendments require a dated note in `06 Rules/` linked from this page, Neutral majority acknowledgment, and a Wire briefing. Until then, this text controls.
