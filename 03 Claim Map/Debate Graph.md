# Debate Graph

How to browse this vault as a linked dispute — not a pile of notes.

Vault entities connect through Obsidian wikilinks under [[Constitution]] §11–§12 and [[Evidence Standards]]. External URLs stay markdown links; internal notes use `[[wikilinks]]` with **readable labels**. Narrative docs must also **explain** each mention so a learner can follow without hopping codes — see [[Writing for Humans]].

## Path

**Claim → Arguments → Sources → Rebuttals**

1. **Claim** — one precise proposition (`C-###` / `C-A###`). Start from [[All Claims Index]] or the locked [[Christianity Truth Stack]].
2. **Arguments** — Pro / Anti cases that target that claim (`A-PRO-###` / `A-ANTI-###`). Hub: [[Arguments Index]].
3. **Sources** — cited evidence notes (`S-###`). Hub: [[Media Index]]. Source challenges live under Evidence Library.
4. **Rebuttals** — cross-attacks on arguments or evidence (`R-###` in `04 Arguments/Rebuttals/` when filed).

Scores and heat live on the Scoreboard: [[Claim Scores]] · [[Hottest Debates]] · [[Probability of Christianity]].

## How to walk one fight

Example: resurrection hinge (learning path)

1. Open [[C-006|Resurrection]] — the claim that Jesus rose from the dead; read statement, **Arguments for / against**, **Key sources**. This layer heavily affects stack truth and probability when status moves.
2. Follow an argument link (e.g. minimal-facts or empty-tomb notes under Arguments) — read thesis, not just the ID.
3. From the argument, open each labeled `[[S-###|source title]]` citation and note what it is supposed to show.
4. Check the opposing claim [[C-A001|Resurrection did not occur]] and its supporting Anti argument(s).
5. Return to [[Hottest Debates]] / [[Claim Scores]] for status — do not treat Wire headlines as score changes.

## Rule of thumb

If a note matters to the dispute, it should be reachable by **wikilinks** from a claim. Prefer labeled `[[Note|human label]]` inside the vault; use markdown links only for external URLs. In Wire and other narrative docs, also explain the point and why it matters ([[Constitution]] §12).
